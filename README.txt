index.html                  QR 접속 시 첫 페이지 (01번 벤치 안내와 동일)
01_havel_bench.html         안내판 앞면: 바츨라프 하벨 벤치
02_havel_timeline.html      안내판 뒷면: 바츨라프 하벨 소개 설명글
00_suyeong_heritage.html    향후 종합 문화유산 페이지 보관용. 메뉴·헤더 어디에도 연결하지 않음
content.js                  한국어·영어·중국어(간체)·일본어·체코어 문안 및 기존 연표 데이터

[업로드 안내]
1. 이 ZIP 파일의 압축을 해제해 모든 파일을 한 폴더에 함께 업로드하세요.
2. QR 주소는 업로드한 폴더의 index.html 또는 01_havel_bench.html URL로 설정하세요.
3. 첫 화면은 바츨라프 하벨 벤치 안내(앞면)입니다.
4. 안내 목록에서 하벨 대통령 소개(뒷면)로 이동할 수 있습니다.
5. 언어 선택: 한국어(ko) / English(en) / 简体中文(zh) / 日本語(ja) / Čeština(cs).
   ?lang=cs 처럼 언어를 지정한 링크를 직접 공유할 수도 있습니다.
6. 00_suyeong_heritage.html은 파일만 보존되며 페이지 내부에서 연결하지 않습니다.
   직접 URL을 입력하면 접근 가능하므로 공개 서버에 올리지 않으면 완전히 비공개로 보관됩니다.

[문안 수정 방법]
- content.js의 bench: 안내판 앞면 각 언어 본문
- content.js의 biography: 안내판 뒷면 각 언어 4개 문단
- content.js의 ui: 제목 / 메뉴 / 버튼 / 안내문
- content.js의 czechFront: 앞면 체코어 원문 병기(체코어 선택 시 중복 표시하지 않음)
- content.js의 timeline: 이전 연혁 7개 항목을 보관해 둔 데이터.
  app.js에서 연혁 데이터를 화면에 출력하지 않도록 했으며, 나중에 필요하면 재사용할 수 있습니다.

[검수 관련]
- 제공한 한국어 및 체코어 문장을 기준으로 앞면·뒷면을 반영했습니다.
- 영문·중문·일문은 자연스러운 안내판용 표현으로 번역한 작업본입니다.
- 체코어 본문은 제공한 원문을 유지했습니다.
- 대사관·발주처 최종 검수 전에는 고유명사·후원 표기·번역을 확정본으로 취급하지 마세요.
- 운영사 표기는 지역 구분에 따라 LINE DESIGN으로 유지했습니다.
